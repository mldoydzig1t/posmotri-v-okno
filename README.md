# Посмотри в окно

Учебный проект (Яндекс Практикум, «Фронтенд-разработчик»): приложение, которое
показывает вид на город глазами жильцов — выбираешь город и время суток, а в окне
появляется фотография, тихая музыка и медленный дрейф кадра.

Весь код написан с нуля под этот продукт: HTML, CSS и JavaScript без фреймворков
и сборки. 15 городов, 45 фотографий и 3 оригинальные фоновые дорожки.

Живая версия: https://posmotri-v-okno.spru.site/

## Что умеет

- выбор города и времени суток (утро / день / ночь);
- окно с фотографией: рама с переплётом, блик на стекле, медленный зум кадра;
- свет в «комнате» меняется вместе с временем суток: рассвет, дневной свет, сумерки;
- фоновая музыка: play/pause, своя дорожка для каждого времени суток;
- состояния: прелоадер, ошибка загрузки снимка, «окно ещё не открыто»;
- последний выбор запоминается в localStorage;
- работа с клавиатуры, видимый фокус, поддержка `prefers-reduced-motion`.

## Структура

```
posmotri-v-okno/

├── styles/

├── scripts/
│   └── app.js          логика: данные, показ вида, музыка, состояния
├── data/
│   └── cities.json     города, снимки, фоновые дорожки
├── audio/              три фоновые дорожки (оригинальный синтез, CC0)
```

## Как запустить

Проект статический, но данные лежат в JSON, поэтому его нужно отдавать по HTTP
(с `file://` браузер заблокирует `fetch`).

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Технические решения

- **Без зависимостей и сборки.** Чистый HTML/CSS/JS, всё в трёх файлах.
- **Логические свойства** (`margin-inline`, `inset-block`, `padding-block`) вместо
  `left/top` — проект двуязычный по структуре и готов к смене направления текста.
- **Grid и Flexbox** для раскладки; `minmax(0, 1fr)` и `aspect-ratio` — чтобы
  длинные названия городов и узкие экраны не ломали сетку.
- **Цвет и типографика — CSS-переменные** в `:root`, тема комнаты переключается
  атрибутом `data-time` у корневого блока.
- **Доступность:** настоящие `<label>`, `fieldset`/`legend`, `role="status"` с
  `aria-live`, `aria-busy` у окна, `aria-label` у иконочной кнопки, `:focus-visible`.
- **Производительность:** изображения грузятся лениво, страница не тянет
  фреймворки, анимация кадра отключается при `prefers-reduced-motion`.
- **Состояния загрузки и ошибки** обрабатываются явно: у снимка есть таймаут в 12
  секунд, ошибка показывается отдельным экраном с кнопкой повтора.

## Источники материалов

Фотографии — Wikimedia Commons, открытые лицензии (CC0 / CC BY / CC BY-SA);
автор и лицензия указаны в `data/cities.json` (поле `author` и `license` у каждого
снимка) и выводятся под кадром в приложении. Музыка синтезирована с нуля для этого
проекта (Python + numpy): три дорожки генерируются скриптом `tools/make_audio.py`
(нужны `numpy` и `ffmpeg`) и кладутся в `audio/`. Внешних запросов за аудио
приложение не делает.

## Что можно улучшить

- подключить API с живыми камерами и вебкамерами вместо фотографий;
- добавить плавный переход между временем суток (кроссфейд);
- сохранять историю просмотренных окон;
- добавить полноэкранный режим и режим «только окно» для медитации.
